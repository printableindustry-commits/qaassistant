Actions à lancer

Cochez les étapes exécutées à la suite — survolez ou cliquez i pour le détail CLI

i

Script : repair.mjs

Argument : --install (alias --fix)

Active la purge (sauf si --no-purge), vérifie Node, met à jour ~/.npmrc, épingle volta.node dans package.json, restaure les dépendances.

i

Script : repair.mjs

Argument : --portable (ou --portable-only)

Ignore Volta et force le runtime dans 01_reparation-poste-travail/vendor/node/. Génère repair-env.cmd à la racine du projet.

i

Script : repair.mjs

Argument : --cypress

Variable d'environnement CYPRESS_INSTALL_BINARY pointée vers le ZIP vendor. Implicite avec --install.

i

Script : download-vendor.mjs

Arguments optionnels :

  • --node-only — ZIP Node uniquement
  • --cypress-only — ZIP Cypress uniquement
  • --modules-only — archive node_modules.tgz du dépôt

Sans argument : télécharge / archive les trois. Nécessite Internet (poste maison).

Options avancées repair.mjs — flags complémentaires
i

Argument : --remove-package-lock

Supprime package-lock.json à la racine du projet avant purge / install.

i

Argument : --no-purge

Désactive la suppression de node_modules, .cypress, caches npm/Cypress. Utile pour diagnostic rapide.

i

Argument : --online

Ignore vendor/node_modules.tgz et exécute npm ci ou npm install contre le registry (voir page .npmrc).

i

Argument : --dry-run

Journalise les opérations prévues (purge, fichiers, commandes) sans modification réelle.

i

Script : repair.mjs sans --install

Arguments utiles : --project, --node, --volta-home

Équivalent à lancer repair sans flags d'installation — seul le bloc diagnostic s'exécute.
